# Dance World - Dance Classes Booking Website

## 🎯 Purpose
This website allows users to view available dance classes and register for their preferred sessions online.

## 🌟 Features
- Responsive design for all screen sizes
- View list of available classes (style, time, instructor)
- Register form with validation and localStorage persistence
- Interactive JavaScript functionality across all pages

## 💻 Tech Stack
- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (DOM Manipulation, localStorage)

## 🐞 Known Bugs
- No backend integration (all data is in localStorage)
- Data will not persist across different browsers/devices

## 📦 How to Run
Open `index.html` in your browser and navigate through the pages using the nav bar.
